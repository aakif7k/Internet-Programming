# Capstone Project: Customer Purchasing Analysis

This directory contains the Capstone Project for the Internet Programming course: **Customer Purchasing Analysis**.

- **Repository Source:** Cloned from [Sooriyavelb/Customer_purchasing_analysis](https://github.com/Sooriyavelb/Customer_purchasing_analysis)
- **Directory:** [`Customer_purchasing_analysis/`](./Customer_purchasing_analysis/)

## Project Overview

The **Customer Purchasing Analysis** project is an end-to-end full-stack data analytics and prediction system designed to analyze retail customer purchasing habits, segment user demographics, and forecast purchasing trends.

### Architecture & Components
- **`frontend/`**: Interactive user interface and dashboard for data visualization and customer insights.
- **`backend/`**: REST APIs, services, and processing pipelines.
- **`r-analytics/`**: Statistical models, exploratory data analysis (EDA), and R visualization scripts.
- **`dataset/`**: Sample customer purchase and transaction datasets.
- **`scripts/`**: Automation and deployment utilities.

For complete setup instructions, API documentation, and execution steps, refer to [Customer Purchasing Analysis Documentation](./Customer_purchasing_analysis/README.md).
