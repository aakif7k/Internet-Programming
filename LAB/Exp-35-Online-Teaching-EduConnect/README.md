# Exp-35-Online-Teaching-EduConnect: EduConnect - Interactive Teaching Platform

## 1. Experiment Overview
- **Experiment No:** 35
- **Course Title:** Internet Programming Lab
- **Category:** Portals & Management
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Interactive learning management system featuring course catalog, student/instructor registration, subject allocation, video lecture streaming, downloadable materials, quizzes, and timetable management.

## 3. Key Actors & System Roles
- **Student**
- **Instructor / Teacher**
- **Academic Admin**

## 4. Implemented Features
- Course catalog: browse certified courses across Web Development, Data Science, AI, and Cloud Computing
- Student registration, course enrollment, and progress tracking dashboard
- Teacher registration and subject allocation by department
- Interactive classroom: video lecture player, downloadable lecture PDFs, and discussion forum
- Interactive knowledge quiz with instant scoring and explanation feedback
- Class schedule & time management timetable with upcoming live sessions
- Teacher course builder: upload lectures, create assignments, track enrolled students
- Admin academic dashboard: monitor active courses, student completion rates, and instructor workload

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
