# Exp-33-Restaurant-Booking-KodaikanalEats: KodaikanalEats - Restaurant & Resort Booking

## 1. Experiment Overview
- **Experiment No:** 33
- **Course Title:** Internet Programming Lab
- **Category:** Booking & Reservations
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Kodaikanal hospitality platform for booking dining tables and resort suites (Single, Double, Deluxe) with seasonal/non-seasonal pricing, room boy availability tracking, and menu ordering.

## 3. Key Actors & System Roles
- **Guest / Tourist**
- **Resort & Restaurant Admin**

## 4. Implemented Features
- Restaurant table reservation: select dining time, party size, indoor/balcony valley-view seating, and dietary preferences
- Resort accommodation booking: browse Single Room ($45/night), Double Room ($75/night), and Luxury Deluxe Suite ($130/night)
- Seasonal vs Non-Seasonal rate toggle with automatic price adjustment
- Real-time room availability checker across calendar dates
- Room boy / housekeeping staff availability tracker and room service assignment
- Local culinary highlights menu and special hill-station offer packages
- Admin dashboard: manage room rates, monitor daily occupancy, assign room attendants, inspect customer booking ledger

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
