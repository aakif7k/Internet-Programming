# Exp-12-Insurance-Management-InsureEasy: InsureEasy - Online Insurance Platform

## 1. Experiment Overview
- **Experiment No:** 12
- **Course Title:** Internet Programming Lab
- **Category:** Portals & Management
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Cutting-edge insurance management platform enabling customers to compare and buy Health, Auto, and Home policies, calculate premiums, file claims, and receive automated SMS renewal alerts via agents.

## 3. Key Actors & System Roles
- **Customer**
- **Insurance Agent**
- **System Admin**

## 4. Implemented Features
- Policy comparison tool across Health, Motor/Auto, Life, and Home insurance
- Instant insurance premium calculation based on coverage amount and age
- Secure online policy application and purchase
- Customer policy dashboard: view active policies, download policy bond, file insurance claim
- Agent registration & administrator approval workflow
- Agent dashboard: create customer record, manage policies, track commission dues
- Simulated SMS alert dispatcher to remind policyholders before due dates
- Admin portal: approve agents, view all agent performance, oversee policy portfolio

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
