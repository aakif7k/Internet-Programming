# Exp-14-Second-Hand-Market-ReNewMarket: ReNewMarket - Second-Hand Goods Marketplace

## 1. Experiment Overview
- **Experiment No:** 14
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Sustainable peer-to-peer marketplace connecting buyers and sellers for pre-loved electronics, furniture, clothing, and books with listing creation, price negotiation simulator, and logistics tracking.

## 3. Key Actors & System Roles
- **Buyer**
- **Seller**
- **Market Administrator**

## 4. Implemented Features
- User authentication & profile management
- Seller module: create commodity listing with title, category, condition (Like New, Good, Fair), photos, and price
- Buyer search and filtering across second-hand categories (Electronics, Furniture, Fashion, Books)
- Interactive 'Make an Offer' / Price Negotiation simulator between buyer and seller
- Order management: track delivery status (Pending, Shipped, In Transit, Received)
- Feedback and seller rating system promoting trust & sustainability
- Administrator dashboard: manage user accounts, manage categories (add/delete), moderate commodity listings, manage logistics status

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
