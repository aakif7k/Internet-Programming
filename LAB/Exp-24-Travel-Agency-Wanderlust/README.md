# Exp-24-Travel-Agency-Wanderlust: Wanderlust Travels - Online Travel Agency

## 1. Experiment Overview
- **Experiment No:** 24
- **Course Title:** Internet Programming Lab
- **Category:** Booking & Reservations
- **Status:** Completed & Fully Functional

## 2. Problem Statement
All-in-one travel agency platform for booking vacation packages, hotels, flights, and food itineraries with interactive destination guides, booking vouchers, and tourism administration controls.

## 3. Key Actors & System Roles
- **Traveler User**
- **Tourism Admin**

## 4. Implemented Features
- Traveler registration, login, and travel preferences profile
- Browse holiday destinations with curated photo galleries, highlights, and climate guides
- Explore vacation packages: combined flights, luxury hotel stays, guided routes, and meal plans
- View hotel & hostel accommodation details with room options and pricing
- Booking engine: book complete travel package or customized accommodation with instant confirmation voucher
- My Bookings dashboard: view upcoming trips, download travel vouchers, cancel bookings
- Admin portal: post new tourism destinations, manage hotel tie-ups, configure dining packages, inspect customer booking logs

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
