# Exp-11-Real-Estate-HomeFinder: Home Finder - Real Estate Platform

## 1. Experiment Overview
- **Experiment No:** 11
- **Course Title:** Internet Programming Lab
- **Category:** Portals & Management
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Real estate discovery platform for residential and commercial properties with advanced search filters, saved criteria, interactive map visualization, mortgage EMI calculator, and viewing scheduler.

## 3. Key Actors & System Roles
- **Property Buyer / Renter**
- **Real Estate Agent / Admin**

## 4. Implemented Features
- User login/registration with saved search criteria feature
- Comprehensive property search: filter by location, price budget, property type (Apartment, Villa, Commercial, Plot), and BHK
- Interactive map location visualization for property listings
- Detailed property listings: high-resolution photos, amenities, floor plans, neighborhood info
- Built-in Mortgage & Loan EMI Calculator
- Schedule a property viewing form with agent notification
- Agent & real estate company search directory
- Admin property management: add/edit property, manage seller listings, view visitor statistics

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
