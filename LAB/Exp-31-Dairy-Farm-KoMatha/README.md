# Exp-31-Dairy-Farm-KoMatha: Ko-Matha Smart Dairy Farm Management

## 1. Experiment Overview
- **Experiment No:** 31
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Smart dairy farm portal showcasing Indian A1 cow milk products (milk, curd, cova-sweet, butter, ghee), customer online ordering, daily/monthly stock inventory reports, and milk vendor collection records.

## 3. Key Actors & System Roles
- **Customer**
- **Farm Administrator**
- **Milk Vendor**

## 4. Implemented Features
- Farm showcase: heritage of Indian A1 cows, organic milking practices, hygiene testing, and health benefits
- Online Dairy Store: fresh A1 milk, curd, traditional cova-sweet, churned butter, and pure cow ghee with package sizes and pricing
- Customer online order placement with recurring daily/weekly delivery schedule
- Admin stock maintenance: daily milk production entry form, wastage log, and sales tracking
- Automated inventory reports: Daily, Monthly, and Yearly milk yield and product sales analytics
- Milk Vendor Management: registered vendor information, daily milk procurement logs, fat content quality testing, and cow health records

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
