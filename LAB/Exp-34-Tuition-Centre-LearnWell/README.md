# Exp-34-Tuition-Centre-LearnWell: LearnWell Tuition Centre Management System

## 1. Experiment Overview
- **Experiment No:** 34
- **Course Title:** Internet Programming Lab
- **Category:** Portals & Management
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Comprehensive tuition centre management website managing course offerings, online/offline student enrollments, fee payment tracking, teacher allocations, academic progress reports, and maintenance requests.

## 3. Key Actors & System Roles
- **Student / Parent**
- **Teacher / Tutor**
- **Centre Admin**

## 4. Implemented Features
- Centre announcements board for class schedules, exam revisions, and holiday notices
- Subject catalog: Mathematics, Physics, Chemistry, Biology, and Computer Science with course duration, fee structure, and Online/Offline mode toggle
- Student registration and course enrollment with digital fee payment simulation
- Teacher portal: manage assigned classes, mark attendance, and log student performance feedback
- Student dashboard: view enrolled subjects, fee receipts, class timetable, and submit maintenance/help requests
- Admin analytics: monthly and yearly fee collection reports, teacher-subject allocation matrix, student enrollment trends

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
