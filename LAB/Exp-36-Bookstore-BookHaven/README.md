# Exp-36-Bookstore-BookHaven: BookHaven - Online Bookstore

## 1. Experiment Overview
- **Experiment No:** 36
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Online bookstore featuring bestseller book carousel, genre catalog filters (Fiction, Non-fiction, Academic), book preview modal, shopping cart, FAQs accordion, customer reviews, and literary blog.

## 3. Key Actors & System Roles
- **Reader / Customer**
- **Bookstore Admin**

## 4. Implemented Features
- Homepage with bestseller carousel, new release highlights, and editor's picks
- Catalog page with multi-criteria filtering: genre (Fiction, Science Fiction, Business, Self-Help, Academic), author, and price slider
- Book details modal: book cover, synopsis, author bio, rating stars, and customer reviews
- Interactive shopping cart with item quantity adjustments and checkout summary
- Literary Blog section sharing book reviews, author interviews, and reading lists
- Customer Support FAQ accordion covering shipping, returns, and orders
- Privacy policy page and store contact information
- Admin portal: add new book titles, update inventory stock, manage featured collections

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
