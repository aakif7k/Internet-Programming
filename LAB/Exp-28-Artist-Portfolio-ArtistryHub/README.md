# Exp-28-Artist-Portfolio-ArtistryHub: ArtistryHub - Emily Harris Artist Portfolio

## 1. Experiment Overview
- **Experiment No:** 28
- **Course Title:** Internet Programming Lab
- **Category:** Portfolios, Blogs & Content
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Bespoke digital portfolio celebrating artist Emily Harris featuring high-res artwork gallery, career biography timeline, discography/bibliography archives, media interview gallery, exhibition updates, and print store.

## 3. Key Actors & System Roles
- **Art Enthusiast / Collector**
- **Artist / Curator**

## 4. Implemented Features
- Engaging homepage with artistic hero banner, featured artworks, and artist vision statement
- About the Artist: comprehensive biography, creative influences, studio story, and high-quality artist portraits
- Categorized Art Portfolio: Oil Paintings, Watercolor, Sculptures, and Digital Works with lightbox preview and descriptions
- Discography & Bibliography: comprehensive catalog of published art monographs, books, exhibition catalogs with ISBNs
- Media Gallery: video interview player, press articles, podcasts, and exhibition vernissage recordings
- Exhibitions & Events: upcoming gallery exhibitions with dates and venue locations
- Interactive features: art print shop preview, newsletter subscription, and booking/inquiry form

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
