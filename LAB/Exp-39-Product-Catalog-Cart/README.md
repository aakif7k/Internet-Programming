# Exp-39-Product-Catalog-Cart: TechStore - Clean Product Catalog & Cart

## 1. Experiment Overview
- **Experiment No:** 39
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
E-commerce product catalog with category navigation, real-time search, price filtering, dynamic cart drawer, tax/shipping calculations, streamlined checkout, and simulated email confirmation.

## 3. Key Actors & System Roles
- **Customer**
- **Store Operator**

## 4. Implemented Features
- Clean and intuitive homepage showcasing featured products and category tabs (Electronics, Wearables, Accessories)
- Instant product search bar and filter by price range and rating
- Product cards with high-res imagery, price, stock status, and single-click 'Add to Cart'
- Interactive Shopping Cart drawer: increment/decrement quantities, remove items, clear cart, dynamic subtotal and tax calculation
- User Account management: saved shipping addresses and simulated past order history
- Streamlined two-step checkout process with credit card/UPI mock payment
- Order confirmation modal with unique order ID, itemized receipt, and simulated email confirmation dispatch

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
