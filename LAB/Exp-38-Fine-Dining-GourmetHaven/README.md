# Exp-38-Fine-Dining-GourmetHaven: Gourmet Haven - Fine Dining Restaurant

## 1. Experiment Overview
- **Experiment No:** 38
- **Course Title:** Internet Programming Lab
- **Category:** Portfolios, Blogs & Content
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Restaurant website featuring rotating ambiance carousel, categorized fine dining menu with prices, online table reservation calendar, executive chef profile, culinary philosophy, and patron reviews.

## 3. Key Actors & System Roles
- **Dining Guest**
- **Restaurant Manager**

## 4. Implemented Features
- Atmospheric homepage with rotating image carousel of dining ambiance and signature culinary creations
- About Us: restaurant heritage, farm-to-table culinary philosophy, and Executive Chef bio
- Interactive Categorized Menu: Appetizers, Main Courses, Chef's Specials, Artisan Desserts, and Wine Pairings with allergen tags and pricing
- Online Table Reservation System: date picker, time slot selector, guest count, seating area (Main Dining Room, Private Wine Cellar, Garden Terrace)
- Special Offers & Events section: tasting menus, weekend jazz brunch, and seasonal celebrations
- Patron Testimonials and Michelin-standard culinary reviews
- Contact & Location page: interactive map widget, address, opening hours, and private dining inquiry form

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
