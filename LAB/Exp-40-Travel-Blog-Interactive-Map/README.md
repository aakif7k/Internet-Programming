# Exp-40-Travel-Blog-Interactive-Map: Travel Explorer - Interactive Travel Blog

## 1. Experiment Overview
- **Experiment No:** 40
- **Course Title:** Internet Programming Lab
- **Category:** Portfolios, Blogs & Content
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Travel blog with interactive world map highlighting visited destinations, filterable adventure narratives, rich photo galleries, reader comment threads, travel packing tools, and author biography.

## 3. Key Actors & System Roles
- **Travel Reader**
- **Travel Blogger**

## 4. Implemented Features
- Inviting homepage with recent travel stories, featured expeditions, and clean navigation
- Interactive Visited Destinations Map: interactive coordinates pins linking directly to corresponding location journals
- Destination filter: browse articles by continent (Europe, Asia, Americas, Africa) and travel style (Solo, Adventure, Foodie)
- Immersive Blog Articles: rich narrative text, location travel tips, and responsive photo slideshow galleries
- Interactive Reader Comments: post feedback, ask travel questions, and join community discussions
- About the Traveler: author biography, travel milestones, camera gear, and essential packing checklists
- Social media share shortcuts to expand article reach

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
