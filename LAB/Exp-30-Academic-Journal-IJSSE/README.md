# Exp-30-Academic-Journal-IJSSE: IJSSE - Academic Journal Publishing Portal

## 1. Experiment Overview
- **Experiment No:** 30
- **Course Title:** Internet Programming Lab
- **Category:** Portals & Management
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Official publisher portal for the International Journal of Scientific and Social Excellence (ISSN 2395-1443 / 2395-1451) with dedicated Author, Reviewer, and Editor workflows, manuscript tracking, and article archives.

## 3. Key Actors & System Roles
- **Author**
- **Peer Reviewer**
- **Managing Editor**
- **Reader**

## 4. Implemented Features
- Journal homepage with aims, scope, indexing credentials (Scopus indexed), print ISSN 2395-1443 and online ISSN 2395-1451
- Author Portal: manuscript submission form, download manuscript template & copyright form, fee guidelines, and real-time paper status tracking
- Reviewer Portal: reviewer registration, assigned papers queue, structured manuscript evaluation rubric (originality, methodology, clarity)
- Editor Portal: editorial board directory, assign manuscripts to peer reviewers, review recommendation verdicts (Accept, Revisions, Reject)
- Article Repository: Current Issue, Archive volumes, Most Viewed and Most Cited papers with DOI citations
- Call for Papers announcements, newsletter subscription, and editorial contact desk

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
