# Exp-06-Cake-Ordering: Online Cake Ordering System

## 1. Experiment Overview
- **Experiment No:** 6
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
E-commerce platform for ordering cakes with category/flavor/occasion filters, custom cake sizes & messages, eggless options, shopping cart, shipping address management, delivery tracking, and bakery admin product manager.

## 3. Key Actors & System Roles
- **Customer**
- **Bakery Admin**

## 4. Implemented Features
- Customer registration and login
- Browse cakes by Category (Birthday, Wedding, Anniversary, Festive)
- Filter by Flavor (Chocolate Truffle, Red Velvet, Black Forest, Pineapple, Vanilla) and Price Range
- Customization options: Size (0.5kg, 1kg, 2kg, 3kg), Custom Inscription Message, Eggless toggle
- Add to Cart, cart drawer with quantity edit, and order placement
- Shipping address manager (add/update delivery location)
- My Orders dashboard with real-time shipping/delivery status tracking
- Admin portal to post cake details, upload images, manage prices, and update order statuses

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, cart updates, and administrative modifications).
