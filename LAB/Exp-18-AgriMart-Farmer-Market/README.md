# Exp-18-AgriMart-Farmer-Market: AgriMart - Farmer Supplies Marketplace

## 1. Experiment Overview
- **Experiment No:** 18
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Agricultural commerce portal empowering farmers to sell produce and buy seeds, fertilizers, and equipment. Features farmer sales dashboard, buyer shopping cart, wallet balance, and shipping tracker.

## 3. Key Actors & System Roles
- **Farmer / Producer**
- **Public Buyer**

## 4. Implemented Features
- Farmer & buyer registration with OTP mobile verification
- Farmer Dashboard: add agricultural products (seeds, organic fertilizers, pesticides, farm equipment, tools), upload photos, set stock and prices
- Farmer Sales tracker: view orders, manage shipping status, view revenue earnings
- Public Buyer Portal: search and filter agricultural supplies by category and price
- Buyer e-Wallet balance management with top-up feature
- Shopping cart, shipping address manager, order placement, and live shipment tracking
- Direct product inquiries and farmer support

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
