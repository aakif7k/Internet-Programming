# Exp-05-Flight-Reservation: Online Flight Reservation System

## 1. Experiment Overview
- **Experiment No:** 5
- **Course Title:** Internet Programming Lab
- **Category:** Booking & Reservations
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Web-based airline reservation system consolidating flight data, real-time seat inventory, fare classes, payment simulation, e-ticket generation, cancellation with refund, customer feedback, and admin flight analytics.

## 3. Key Actors & System Roles
- **Passenger**
- **Airlines Admin**

## 4. Implemented Features
- Flight search by origin, destination, date, and travel class (Economy, Business, First)
- Real-time seat inventory and dynamic flight fare display
- Seat selection and passenger details entry
- Secure payment gateway simulation with instant PNR generation
- My Tickets dashboard with printable e-Tickets & travel itinerary
- Cancel ticket workflow with cancellation fee and refund computation
- Customer feedback & rating submission
- Admin login & flight schedule management
- Admin booking status viewer and flight revenue reports

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, cart updates, and administrative modifications).
