# Exp-21-Job-Portal-Vacancy: JobPortal - Vacancy & Recruitment Platform

## 1. Experiment Overview
- **Experiment No:** 21
- **Course Title:** Internet Programming Lab
- **Category:** Portals & Management
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Online employment platform enabling company directors to post job vacancies and review candidate resumes, while job seekers search vacancies, filter by category/location, and submit online applications.

## 3. Key Actors & System Roles
- **Job Seeker**
- **Company Director / HR**
- **Portal Admin**

## 4. Implemented Features
- Job seeker registration, profile creation, and resume details upload
- Company Director registration with admin approval workflow
- Director portal: post new job vacancies (title, department, experience, salary range, description, contact)
- Job seeker vacancy search with filters for job category, location, and employment type
- One-click job application with cover letter and qualification summary
- Director applicant tracking: review applied candidates, download resumes, shortlist or reject candidates
- Job seeker applied jobs dashboard with status updates (Applied, Shortlisted, Interview Scheduled)
- Admin management: approve directors, monitor active vacancies, view recruitment statistics

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
