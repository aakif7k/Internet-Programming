# Exp-08-Hospital-Appointment-Booking: MedCare Hospital Online Appointment Booking

## 1. Experiment Overview
- **Experiment No:** 8
- **Course Title:** Internet Programming Lab
- **Category:** Booking & Reservations
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Hospital appointment booking platform allowing patients to search doctors by specialty and location, schedule convenient slots, submit online check-in details, view past medical visits, and rate doctors.

## 3. Key Actors & System Roles
- **Patient User**
- **Hospital Admin / Doctor**

## 4. Implemented Features
- Patient registration, login, and medical profile management
- Search doctors by medical specialty (Cardiology, Orthopedics, Pediatrics, Dermatology, Neurology)
- Doctor profiles with qualifications, consultation fees, and patient ratings
- Slot picker for flexible date and time appointment booking
- Online pre-appointment check-in form (symptoms, allergies, medical history)
- Appointment management (upcoming visits, cancellation, reschedule)
- Past appointment history and digital prescription notes
- Doctor review and rating system
- Hospital admin dashboard: doctor directory, appointment statistics, department analytics

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, cart updates, and administrative modifications).
