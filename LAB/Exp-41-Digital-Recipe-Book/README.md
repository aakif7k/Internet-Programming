# Exp-41-Digital-Recipe-Book: CulinaryDelight - Digital Recipe Book

## 1. Experiment Overview
- **Experiment No:** 41
- **Course Title:** Internet Programming Lab
- **Category:** Portfolios, Blogs & Content
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Digital culinary platform featuring categorized recipes, dynamic serving size ingredient scaler, step-by-step cooking mode, user reviews, recipe search/filter, and weekly meal planner with shopping list export.

## 3. Key Actors & System Roles
- **Home Cook**
- **Recipe Creator**

## 4. Implemented Features
- Curated recipe collection categorized by meal type (Breakfast, Mains, Desserts, Beverages) and dietary tags (Vegetarian, Vegan, Gluten-Free, Keto)
- Recipe search bar and multi-filter (cooking time, difficulty level, cuisine)
- Detailed Recipe Page: dish photography, prep & cook times, calories, and user star ratings
- Dynamic Serving Size Scaler: change serving count (e.g. 2 to 4 to 8) to automatically recalculate all ingredient quantities in real-time
- Step-by-step Interactive Cooking Mode with ingredient check-off
- Community comments and review ratings section
- Weekly Meal Planner & automatic shopping list generator with export/print capability

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
