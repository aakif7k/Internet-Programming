# Exp-37-Professional-Showcase-Portfolio: MyProfessionalShowcase - Portfolio & Resume

## 1. Experiment Overview
- **Experiment No:** 37
- **Course Title:** Internet Programming Lab
- **Category:** Portfolios, Blogs & Content
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Portfolio website presenting professional bio, categorized skill bars, featured projects gallery with live demos, interactive career timeline, downloadable resume, testimonials, and contact form.

## 3. Key Actors & System Roles
- **Recruiter / Client**
- **Portfolio Owner**

## 4. Implemented Features
- Hero section with professional introduction, key specialties, and call-to-action buttons
- About Me page: career journey, educational background, philosophy, and colleague testimonials
- Skills Matrix: technical skills categorized into Frontend, Backend, Database, and DevOps with proficiency indicators
- Interactive Portfolio: filterable project cards with descriptions, tech stacks, live demo links, and GitHub repository links
- Interactive Resume Page: chronological milestone timeline of work experience, education, certifications, and one-click printable/downloadable resume modal
- Tech Insights Blog: articles on modern web architecture and engineering practices
- Contact Form with instant message validation and professional social media links

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
