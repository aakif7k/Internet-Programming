# Exp-13-Flowers-Gifts-BlossomGifts: BlossomGifts - Flowers & Gifts Ordering

## 1. Experiment Overview
- **Experiment No:** 13
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
User-friendly gift and flower shop categorized by occasion, recipient, and price range, with custom delivery date scheduler, personalized card messages, cart, order summary, and admin inventory control.

## 3. Key Actors & System Roles
- **Customer**
- **Store Admin**

## 4. Implemented Features
- Browse floral arrangements, gift baskets, and personalized gifts by occasion (Birthday, Anniversary, Romance, Congratulation)
- Filter by recipient (For Him, For Her, For Parents) and price range
- Customization options: select delivery date & time slot, add custom greeting card text
- Shopping cart with item adjustments and clear order summary
- Simulated checkout with email/SMS order confirmation
- Real-time order tracking and past order history
- Customer inquiry form via email simulator
- Admin inventory management: add new bouquet/gift, modify price, update description, delete out-of-stock items

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
