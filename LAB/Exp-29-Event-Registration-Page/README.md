# Exp-29-Event-Registration-Page: TechCon - Event Landing & Registration Page

## 1. Experiment Overview
- **Experiment No:** 29
- **Course Title:** Internet Programming Lab
- **Category:** Portfolios, Blogs & Content
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Modern conference landing page with featured keynote speakers, conference agenda schedule chunks (morning/afternoon), venue information with map, audience breakdown, and ticket registration form.

## 3. Key Actors & System Roles
- **Event Attendee**
- **Event Organizer**

## 4. Implemented Features
- Engaging header with conference countdown timer, dates, venue, and primary CTA
- Keynote Speakers showcase: speaker cards with headshots, topics, corporate affiliations, and social links
- Chunked Conference Schedule: interactive tabbed timeline for Day 1 and Day 2 (Keynote, Breakout sessions, Lunch, Panel, Networking)
- Event Purpose & Target Audience section: clearly defining who should attend (Engineers, Founders, Researchers, Students)
- Interactive Venue guide with map representation, directions, and nearby accommodation
- Attendee Registration Form: ticket tier selection (Student, Standard, VIP), participant details, dietary requirements, and instant ticket pass generation

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, calculations, and administrative actions).
