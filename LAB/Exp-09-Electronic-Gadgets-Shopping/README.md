# Exp-09-Electronic-Gadgets-Shopping: TechSavvy - Electronics Shopping Platform

## 1. Experiment Overview
- **Experiment No:** 9
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Feature-rich electronics e-commerce store with categorized gadget catalog (Smartphones, Laptops, Tablets, Audio), search/filter, dynamic cart, order checkout, order tracking, and admin product/pricing controls.

## 3. Key Actors & System Roles
- **Shopper**
- **Store Admin**

## 4. Implemented Features
- User registration, login, and persistent session
- Categorized catalog: Smartphones, Laptops, Tablets, Smartwatches, Audio & Accessories
- Instant keyword search and price filter
- Detailed product view with specifications, availability stock, and customer reviews
- Interactive shopping cart: add, update quantity, remove, and live subtotal/tax calculation
- Multi-step checkout with shipping address and simulated payment
- Order tracking with status workflow (Processing, Dispatched, In Transit, Delivered)
- Order history with past receipts
- Admin inventory management: add new gadget, edit price, update description, delete item, view customer checkout list

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, cart updates, and administrative modifications).
