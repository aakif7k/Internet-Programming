# Exp-10-Fashion-Store-StyleHub: StyleHub - Online Fashion Retailer

## 1. Experiment Overview
- **Experiment No:** 10
- **Course Title:** Internet Programming Lab
- **Category:** E-Commerce & Marketplaces
- **Status:** Completed & Fully Functional

## 2. Problem Statement
Premier fashion e-commerce platform offering clothing, footwear, and accessories for Men, Women, and Kids with size guides, customer reviews, wishlist, cart, returns policy, and admin inventory management.

## 3. Key Actors & System Roles
- **Fashion Shopper**
- **Store Admin**

## 4. Implemented Features
- Clean navigation with categories: Men, Women, Kids (Casual, Formal, Seasonal collections)
- Interactive size guide modal (S, M, L, XL, XXL) with chest/waist measurements
- High-resolution image galleries, product reviews, and star ratings
- Wishlist system to save favorite apparel items
- Shopping cart with quantity editor and coupon discount code support
- Secure checkout and simulated payment processing
- Order tracking and hassle-free return/exchange request module
- Admin dashboard: add fashion items, update pricing and descriptions, track customer orders

## 5. Technology Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Design System:** Responsive CSS Grid & Flexbox, Custom Design Tokens (`../assets/common.css`)
- **Interactive Logic:** Vanilla JavaScript (`../assets/common.js`), LocalStorage persistence, Dynamic DOM manipulation
- **Compatibility:** Standard modern browsers (Chrome, Firefox, Safari, Edge)

## 6. How to Run & Test
1. Open `index.html` in any web browser.
2. Toggle between system roles using the tabbed navigation.
3. Perform end-to-end interactions (searches, bookings, cart updates, and administrative modifications).
